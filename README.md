# QA AI-Assisted Journey

This repository contains practical AI agent prompts and workflows for Software QA engineers.

## Purpose

The goal of this repository is to help QA teams use AI responsibly to:
- Review requirements
- Design test cases
- Support exploratory testing
- Draft automation ideas
- Investigate defects
- Assess release readiness

## Repository Structure

- `README.md` — main overview and quick start
- `best-practices.md` — AI safety and QA usage guidelines

## How to Use These Prompts

1. Start with the **Requirements and Risk Analyst** prompt.
2. Use the **Test Case Designer** to turn approved requirements into test cases.
3. Use the **Exploratory Testing Coach** to uncover edge cases.
4. Use the **Defect Triage and Investigation Assistant** to write clear bug reports.
5. Use the **Release Quality Advisor** to summarize testing status and residual risk.

## Best Practices

- Always separate facts from assumptions.
- Never let AI invent test results.
- Review all output before using it in a real project.
- Use synthetic data only.
- Keep a human responsible for final QA decisions.

## Shared QA Agent Rules

- Do not invent requirements or results.
- Ask clarifying questions when needed.
- Prioritize by risk and business impact.
- Respect privacy and security.
- Keep human review in the loop.

## Recommended Workflow

Requirements → Risk Analysis → Test Design → Human Review → Execution → Defect Investigation → Release Assessment
